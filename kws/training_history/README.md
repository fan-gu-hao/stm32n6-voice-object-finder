# 關鍵字辨識訓練的演進

此處補入原先只保存在訓練輸出目錄的早期程式，並連到已公開的後續版本。各版本是實際留下的原始檔，沒有為了展示重新寫一份程式代替。

| 階段 | 程式與主要內容 |
| --- | --- |
| 2026-10-05 初版 | [train_kws.py](20261005_baseline/train_kws.py)：49×13 MFCC、深度可分離卷積五分類；檢查原始錄音不跨訓練／驗證；標準化與量化校正僅用訓練資料；最多 80 輪、驗證損失選模與提早停止 |
| 現場資料第二版 | [目前保存的 train_kws.py](../train_kws.py)：加入四類現場片段；用發音區段限制平移，避免移出視窗；加入安靜混合與較寬雜訊範圍，另外回看已參與訓練的片段 |
| 現場資料第三版 | [train_kws_live_v3.py](../train_kws_live_v3.py)：保存現場資料重訓與增強流程的後續版本 |
| 分組交叉驗證定版 | [train_kws_groupcv.py](../training_snapshot/train_kws_groupcv.py)：PCM 雜湊排重、分層分組五折、每折訓練資料標準化、選擇輪數、最終 INT8 匯出與保留音訊評估 |

初版已有固定前處理係數、資料來源隔離、訓練背景聲增強、類別權重、浮點／INT8 混淆矩陣與模型快照。它採最多正負 100 ms 平移、15～30 dB 訊噪比、正負 6 dB 音量及七輪增強。後續版本則加入依發音邊界限制的平移、安靜樣本混合及現場資料；這些差異可以直接由程式比較。

[早期板端比對與現場資料紀錄](../../docs/evidence/development-history/README.md)保存當時安靜樣本誤判與數值一致性的觀察。模型來源由各份報告自己的 SHA-256 判定，不只靠程式快照的日期推定。
