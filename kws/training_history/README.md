| 早期即時辨識不符預期 | 保存了模型偏向 phone 的現象；因此加入固定輸入比較，分開檢查模型移植與音訊前處理 |
| 固定五類比較 | INPUT 與 PCM 兩路各 5/5 分類正確；每例 637 個 INT8 特徵完全一致。兩路的 silence 輸出最大整數差異為 1，其餘為 0 |
| 四例現場診斷 | silence、cup、bottle、phone 的輸入特徵仍完全一致，輸出最大整數差異分別為 0、0、3、1；silence 在板端與兩條電腦路徑都誤判 phone，指向這筆現場資料上的模型問題 |
| 加四段補訓 | 2026-10-07 將訓練資料由 142 增至 146 段，驗證維持 49 段；浮點／INT8 皆為 48/49（97.96%）。四段補訓樣本回看皆分類正確，但它們已進入訓練，不能算獨立驗證 |

[早期板端比對與現場資料紀錄](../../docs/evidence/development-history/README.md)保存安靜樣本誤判、數值一致性與收集清單；[原始開發歷程審閱](../../docs/original-history-review.md)補入固定 CMP 輸出及重訓完成的對話證據。模型來源由各份報告自己的 SHA-256 判定，不只靠程式快照的日期推定。

## 資料隔離與結果界線

分組階段的 227 段開發資料由原先 142 段訓練與 49 段驗證、四段現場診斷音訊，以及新收集的 32 段訓練資料組成。原先固定的 49 段因此改為參與分組交叉驗證，另以新收集的 16 段作保留評估；這 16 段不參與訓練與選輪。早期的 48/49 與定版的 15/16 使用不同的評估集合。

分組程式以原始錄音為群組，並把含有相同 PCM 的來源群組合併，避免重複音訊分散到訓練與驗證兩側；這不是把所有重複樣本逐筆刪除。它也拒絕開發資料與保留資料重疊、檢查標籤衝突，並只用各折訓練部分估計標準化參數、建立背景聲增強與量化校正資料。

五折最佳輪數為 `[82, 28, 66, 9, 79]`。原始訓練附件從第 5 折後段開始，包含五折彙總、完整最終第 1～66 輪、INT8 匯出及保留評估；不能稱為五折所有訓練輪次的完整日誌。五折結果用於開發與選輪，不是額外的獨立測試集。

最終浮點與 INT8 模型在 16 段保留音訊上皆為 15/16（93.75%），分類結果一致。錯誤的 `cup/take_45.wav` 被判為 phone，但 INT8 的 phone 分數只有 60.9375%，未達 90% 命令門檻。命令分類正確且通過單窗分數條件為 11/12，非命令誤通過為 0/4；尚未涵蓋音量門檻、連續命中及冷卻規則，不能與板上六次正確接受混成同一項測試。詳見[保留音訊報告](../../docs/evidence/kws-int8-holdout.json)與[結果說明](../../docs/results.md)。
